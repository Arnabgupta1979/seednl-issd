# G01 facilitator note (pilot, for review)

**Purpose.** Help participants see that farmers use several seed routes, that each route meets some needs and misses others, and that the answer changes with the farmer, crop and season. Supports proposed Module 1 and, lightly, Objective 1 of the V2.0 concept note.

**Time.** About 15–20 minutes per farmer. Two farmers plus a debrief fit in 40–45 minutes.

**Before you start.** Say that all farmers are fictional. Ask for a guess: "Which seed source is best?" Keep the guesses visible.

**Flow.**
1. Pick a farmer. Ask what matters most to them before looking at routes.
2. Choose a main route and an optional back-up. Mixing is realistic.
3. Stress test: try more than one disruption.
4. Read the fit report. The symbols are a conversation aid, not a score.
5. Debrief with the five reflection questions. Run a second farmer and use the compare table.

**Watch for.**
- Naming one winner for all three farmers. Ask what changes with crop or cash.
- Treating company seed as automatically right or saved seed as automatically inferior.
- Reading symbols as points.
- Treating the fictional cases as evidence about a real country.

**Debrief questions.** See the app (screen 6) and `00_Mapping_Storyboard_Debrief.md`.

**Open the app with facilitator notes on:** add `?facilitator=1` to the address, or use the "Facilitator notes" button in the footer. (If an LMS strips the query string, use the button.)

**Limits.** Generic statements and ratings are unverified and need review by a seed-systems expert. Learner group and depth are not yet decided.
